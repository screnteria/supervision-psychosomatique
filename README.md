# Supervision psychosomatique

destinées aux médecins-assistant·es en formation postgraduée FMH en
gynécologie-obstétrique.

Dre méd. Saira-Christine Renteria, Lausanne.

Portail: https://screnteria.github.io/supervision-psychosomatique/

Reproduction ou réutilisation en formation soumises à son accord.
